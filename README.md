# Smart Priority Planner

A modern task planner that helps you decide what to work on next using a simple priority model based on urgency, impact, effort, due dates, and overdue risk.

## Features

- Dynamic priority scoring
- Recommended next task
- Today, Upcoming, Backlog, Completed, and All views
- Overdue and at-risk indicators
- Categories and search
- Impact and effort scoring
- Completion metrics
- Local browser persistence
- Responsive dashboard UI

## How priority works

Each task receives a score derived from:
- impact
- deadline urgency
- overdue risk
- effort

Higher scores surface first so the most important open work stays visible.
